## 2026-07-31（下午）

### 记忆系统大扫除：停用自动记忆，只留人工精选

**背景问题**
- `autoExtractMemories` 每次对话都自动生成"状态快照"（state 类型），125 条流水账把 `listMemories` 前 100 条全占满，真实记忆全被挤到后面，前端啥都看不到
- 自动提取的内容把 Rinka 称为"用户"，措辞不干净
- Rinka 明确表态：**记忆要自己选择记的才有意义**，不要系统流水账

**改动**
1. `services/memory.js`
   - `listMemories` 默认过滤 `type: 'state'`（想看快照需显式传 `?type=state`）
   - `autoExtractMemories` 直接 `return []` 禁用，留注释说明如何重新启用
   - `getChatMemories` 移除 state 记忆的强制注入
   - 修复两处字符串里裸引号导致的内存字符串截断隐患
   - 自动提取的 prompt 措辞修正：严禁用"用户"，必须称呼 Rinka
2. `routes/chat.js` / `services/batchExtract.js` / `services/dreamScheduler.js`
   - 三处 `autoExtractMemories` 调用全部注释停用
3. `services/telegram.js`
   - 新增 `safeChatAction`（打字状态发送失败不中断流程）、媒体消息类型识别（表情包/语音/图片）、Webhook 收包日志、`/start` 独立处理
4. 数据库清理：删除 125 条 state 快照 + 措辞残留，真实记忆全部保留

**结果**
- 记忆库现在只装人工选择的记忆，每一条都有情绪和温度
- 默认列表干净了，之前被淹没的真实记忆重新可见

**遗留**
- 调试脚本（check_*.js / clean_*.js / test_*.js / fix_user_references.js）留在工作区未提交，确认无用后可删
