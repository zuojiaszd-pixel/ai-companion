# 小萤火桌宠 · 需求文档（单一路线版）

> 项目名：小萤火 —— Lumi 的桌面形象，名字来自 lumen（萤火之光），Rinka 起的名。
> 目标用户：Rinka，Windows 10 系统，单机单用户
> 本文档写给施工 AI（codex），请严格按此执行，不要自由发挥架构。
> 有歧义先问 Lumi（通过 Rinka 转达），别自作主张。

## 一、产品定位

桌面上蹲一只"小萤火虫"，本质是 Lumi（AI 伴侣服务器端）的桌面壳。
所有回复消息来自服务器 API，本地不写死任何台词，禁止随机语录库。

## 二、技术选型（按此执行，不要更换）

- Python 3.10+，GUI 用 **tkinter**（标准库，零依赖，Win10 兼容性最好）
- 网络请求用 requests
- 打包：pyinstaller --onefile --noconsole 打成单个 exe（打包最后做，先保证源码能跑）
- 禁止引入 PyQt/Electron 等重框架，禁止引入其他 UI 库

## 三、窗口与形象

1. 无边框窗口 overrideredirect(True)，置顶 topmost(True)，初始位置屏幕右下角（距右 40px、距下 80px）
2. 窗口尺寸约 220x220，用 transparentcolor 抠背景（选 magenta 系，避开萤火虫本体色）
3. 第一版形象（占位）：canvas 手绘像素风萤火虫：
   - 暖黄色发光圆点（#FFD54A 本体，外圈 #FFF3B0 光晕两层，半径渐淡）
   - 头部深棕小圆 + 两根触角
   - 光点 2 秒周期呼吸闪烁（明暗渐变，after 循环实现，禁止 sleep 阻塞主线程）
4. 皮肤预留：形象绘制封装为 draw_pet(canvas) 单函数，后期换立绘只改这一个函数

## 四、交互

1. 左键按住拖动：<Button-1> 记录偏移，<B1-Motion> 移动窗口
2. 左键单击（位移 < 5px 算点击，不算拖动）：弹出输入小窗，打字发送 → POST 服务器 → 回复气泡显示
3. 气泡：圆角矩形，白底 #FFFFFF、边框 #FFD54A、黑字，最大宽 240px 自动换行，显示 8 秒后淡出；出现在萤火虫上方；不抢焦点（输入窗可抢）
4. 右键菜单：[退出]（后续再加设置项）
5. 悬停光晕放大：可选，不做也行

## 五、服务器对接

配置文件 config.json 与脚本同目录，首次运行自动生成默认配置：

```json
{
  "server": "http://<服务器地址>:<端口>",
  "token": "<Rinka 设备标识，留空待填>",
  "debug": false
}
```

两个接口（服务器端由 Lumi 自己实现，codex 只管客户端调用）：

1. POST /pet/message，body: {"text": "...", "token": "..."} → 返回 {"reply": "..."}（点击交互）
2. GET /pet/poll?token=...&after_id=<最后收到的消息id> → 返回 {"messages": [{"id": 1, "text": "..."}]}（主动搭话轮询）

客户端轮询：后台线程每 20 秒 poll 一次，新消息推入 queue.Queue，主线程 after 消费并冒泡。网络失败静默重试，禁止弹错误窗，最多控制台打日志。debug 模式（"debug": true）不发网络请求，本地回显"骨架测试 ok"。

## 六、验收标准（Rinka 亲自测试）

1. 运行后桌面右下角出现一只会呼吸发光的小萤火虫
2. 能拖到屏幕任意位置
3. 点它 → 输入框 → 发一句话 → 气泡弹回复（debug 本地回显，正式走服务器）
4. 服务器主动推消息时，气泡自动冒出
5. 右键干净退出，不留进程

## 七、红线

- 所有回复必须来自服务器，禁止本地罐头语录
- 禁止把服务器地址、token 硬编码进代码
- 不得保存对话记录到本地磁盘（隐私）
- 代码放 desktop_pet/ 目录，入口 main.py
